## 3. 要望 → 要件 → 設計 → テストのつながり（例：WISH-CHAT-004）

WISH-CHAT-004（1部屋5人）→ REQ-CHAT-007（全台合計5接続）・REQ-CHAT-008（満席の制限）
→ DES-CHAT-005（`chat_rooms` 行を `FOR UPDATE` でロックして数える＋確保、30秒で回収、ハートビート）・DES-CHAT-002（満席は `ROOM_FULL`、履歴は入室許可時の ack だけ）
→ TST-CHAT-007・008・009・016（1台）、TST-CHAT-018（2台同時）、TST-CHAT-019（異常終了の回収）で確認。

## 4. 残課題

- Vercel（本番）ではリアルタイム通信を動かしていない（`process.env.VERCEL` のとき Socket.IO を接続しない）。公開方法は要確認。
- 強制終了したプロセスの席は最大30秒残る（TST-CHAT-021 で確認）。
- 別インスタンスの新着はポーリング間隔（2秒）ぶん遅れる。
