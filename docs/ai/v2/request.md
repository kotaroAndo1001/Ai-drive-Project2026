# AI対話アプリ V2 要望書

根拠: 授業資料「V2開発実習」の変更要望と共通条件。V1（`/ai`・`/api/ai`）を維持したまま追加する。

## 1. 背景・目的

V1は1問1答（`ai_qa_logs`）のみで、同じ話題の連続質問や話題ごとの分離ができない。V2では会話単位で文脈を引き継ぎ、一覧から切り替えて再開できるようにする。

## 2. 要望

| 要望ID | 内容 |
|---|---|
| WISH-V2-01 | 前のやり取りを踏まえ、同じ会話で追加質問したい |
| WISH-V2-02 | 話題ごとに新しい会話を作成し、一覧から切り替えたい |
| WISH-V2-03 | 再読み込み後も、保存した会話を選んで再開したい |

## 3. 授業の共通条件（確定）

| 項目 | 条件 |
|---|---|
| 会話名 | trim 後 1〜50 Unicode コードポイント |
| 質問 | trim 後 1〜2000 Unicode コードポイント |
| JSON本文 | 16KiB 以内 |
| 画面履歴 | 選択中会話の最新20往復を古い順 |
| Gemini文脈 | 同じ会話の保存済み最新5往復（古い順）＋今回の質問。新規会話の初回は今回の質問のみ |
| 保存成功 | Gemini回答取得とDB保存の両方成功後に 201。1往復＝質問＋回答 |
| 失敗 | 入力を残して復帰。自動再送しない |
| 公開 | 評価は原則ローカル。公開環境では V2 API を停止 |
| 発展（今回やらない） | ログイン、権限、会話名変更・削除、V1履歴の移行 |

## 4. 既存保護

- V1: `/ai`、`/api/ai/*`、`ai_qa_logs` を壊さない
- TOP・TODO・db-check・db-sample を維持
- DB は既存 `db.ts` の `pool` を共有
- V2 は `src/apps/ai/v2/`・`/ai/v2`・`/api/ai/v2`・専用テーブル

## 5. 配置案との差（本リポジトリ）

- V1画面は `views/ai/index.ejs` + `public/js/ai.js`（`public/ai/` は未使用）
- V2も同様に `views/ai/v2/` + `public/js/ai-v2.js` とし、静的ディレクトリ衝突を避ける
- デモ停止は既存の `AI_DEMO_ENABLED`（`true` のときのみ API 有効）を V2 にも適用する
