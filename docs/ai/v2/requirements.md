# AI対話アプリ V2 要件定義書

根拠: `docs/ai/v2/request.md` と授業の共通条件。実装コードは含めない。

## 1. 目的・利用者・開始条件・範囲

- 目的: 話題別に会話を分け、同じ会話では直近文脈を踏まえて追加質問できる
- 利用者: 授業の受講者・採点者（単一利用者・架空データ）
- 開始条件: V1で実 Gemini の質問が 201・履歴保存できること
- 対象: V2画面・API・専用テーブルの追加、`index.ts` への最小マウント
- 対象外（発展）: ログイン、会話名変更・削除、V1履歴移行、ストリーミング

## 2. 必須要件

| 要件ID | 対応WISH/根拠 | 要件 | 受入条件 |
|---|---|---|---|
| REQ-V2-01 | WISH-V2-02 | 会話名を入力して新規会話を作成し、一覧から選べる | A・B の2件を作成し切り替えられる |
| REQ-V2-02 | WISH-V2-02・03 | 選択会話の最新20往復を古い順に表示。空は正常0件。再読込後に一覧から開いて再取得できる | 空の会話で0件表示。再読込後も同じ会話を開ける |
| REQ-V2-03 | WISH-V2-01・03 | 同じ会話の最新5往復＋今回の質問を Gemini に渡す | Aで架空の合言葉を伝え、Aで追加質問して踏まえた回答が得られる |
| REQ-V2-04 | WISH-V2-02 | 会話ごとに表示と送信文脈を分ける | BにAの履歴が出ない。B初回は今回の質問だけが文脈 |
| REQ-V2-05 | WISH-V2-01・共通条件 | 会話名1〜50、質問1〜2000、JSON16KiB。回答と保存完了時だけ201。失敗時は成功扱いにせず入力保持 | 不正入力で保存しない。失敗後も入力が残る |
| REQ-V2-06 | 共通条件 | V1画面・API・履歴と TOP・TODO を維持。公開では V2 API を停止できる | V2操作後も V1/TOP/TODO が動く。停止時 V2 API は 503 |

## 3. 画面20往復と Gemini 5往復の区別

| | 画面 | Gemini |
|---|---|---|
| 件数 | 最新20往復 | 最新5往復＋今回の質問 |
| 順序 | 古い順 | 古い順（末尾が今回） |
| 新規会話初回 | 0件表示可 | 今回の質問のみ |
